🛡 AML Monitoring & Account Approval Dashboard
📌 Project Overview

This project is a Python-based AML (Anti-Money Laundering) Monitoring Dashboard developed using Streamlit.
It allows administrators to review flagged accounts and approve or reject them dynamically through an interactive web interface.

The dashboard updates account status in real-time using Streamlit session state management.

🚀 Features

• Admin panel for reviewing flagged accounts

• Approve / Reject functionality

• Dynamic status updates

• Clean and interactive UI

• Session state data handling

🛠 Tech Stack

• Python

• Streamlit

• Pandas

⚙ How It Works

• Flagged accounts appear with "Pending" status.

• Admin can click Approve or Reject.

• The account status updates instantly.

• System view reflects the updated status during runtime.
